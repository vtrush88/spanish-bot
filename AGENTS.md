# Spanish Bot — Project Guide for Agents

Контекст проекта для AI-агентов, работающих в этом репозитории. Здесь — то, что нужно,
чтобы строить бота: что это, стек, структура, как запускать и тестировать.

## Что это за проект

Телеграм-бот — **персональный тренажёр испанского для мамы** (учит с нуля, весь
интерфейс на русском). Мама сама добавляет слова или фразы; бот через Claude API
дополняет их переводом, произношением (аудио + русская транскрипция) и примером,
затем тренирует тремя способами: карточки с интервальным повторением, проверка
перевода, аудирование. Pull-режим: мама заходит когда хочет и жмёт кнопку.

Один пользователь (мама + Victoria для теста). Данные ключуются по `user_id` — задел
на несколько пользователей без переделки схемы.

## Стек (Вариант A — выбран и зафиксирован)

- **Python + `aiogram`**, Telegram через **long-polling** (без webhook, HTTPS, сертификатов).
- **Хранилище:** SQLite (один файл, без БД-сервера).
- **LLM:** Claude API (Anthropic SDK) — обогащение слов, проверка перевода, транскрипция.
  Структурированный вывод через tool use (форсированная JSON-схема), один повтор на
  несоответствие.
- **TTS:** бесплатный `edge-tts` (голоса Microsoft, испанский); запасной — `gTTS`.
- **Хостинг:** управляемый дешёвый (Railway / Fly.io), всегда онлайн, авто-перезапуск.

Отвергнуто: webhook+serverless (оверкилл для 1 пользователя), локальный хостинг дома
(хрупко). Не переоткрывать без причины.

## Структура (целевая)

```
bot.py            # точка входа: запуск, роутинг, регистрация хендлеров
config.py         # env: TELEGRAM_TOKEN, ANTHROPIC_API_KEY, ALLOWED_USER_IDS
handlers/         # только разговор с Telegram (кнопки, приём текста) — тонкие
  menu.py · add.py · training.py
services/
  enrichment.py   # Claude: слово/фраза → перевод, транскрипция, пример (чистый dict)
  grading.py      # Claude: проверка маминого перевода (прощает опечатки)
  tts.py          # edge-tts: испанский текст → голосовое (ogg)
  srs.py          # чистая функция интервального повторения
db.py             # SQLite: CRUD карточек + выборка «к повторению»
tests/
```

**Принципы:** хендлеры тонкие, вся логика в `services`/`db`/`srs`. `srs` — чистая
функция без побочных эффектов, тестируется первой (TDD). Доступ — только
`ALLOWED_USER_IDS`, на чужих не реагируем.

## Ключевые решения (не переоткрывать без причины)

- **Контент курирует мама**, бот обогащает (а не готовый курс).
- **2 кнопки в карточках** («Помню / Не помню») + Leitner-лесенка `1→3→7→14→30→60` дней;
  «Не помню» → сброс на 1 день. Логика — в `srs.next_state(card, remembered) → (interval, due_at)`.
- **Аудио кэшируется** через Telegram `file_id` — не перегенерируем TTS на каждом показе.
- **Graceful degradation:** ошибка Claude → сохранить карточку `enriched=false`, дообогатить
  позже; ошибка TTS → карточка с текстом+транскрипцией без голосового; не-текст → мягкая подсказка.

## Как запускать и тестировать

> Пока не реализовано (проект в фазе дизайна). По мере сборки заполнить реальными командами.

Ожидаемо:
- Зависимости: `pip install -r requirements.txt` (или `uv`).
- Запуск локально: `python bot.py` (нужны env-переменные из `config.py`).
- Тесты: `pytest` — приоритет на `tests/` для `srs`, `db`, `enrichment`/`grading` (с моками
  Claude), без живого Telegram и реальных вызовов API.
- Секреты — в `.env` (в `.gitignore`), не коммитить токены/ключи.
