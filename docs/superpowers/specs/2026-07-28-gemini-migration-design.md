# Миграция LLM: Claude API → Google Gemini (бесплатный тир)

**Дата:** 2026-07-28
**Статус:** дизайн утверждён, готов к плану реализации

## Зачем

Бот должен работать **полностью бесплатно** — без привязанной карты, подписок и счетов
(решение Victoria, 2026-07-28). Сейчас обогащение карточек и проверка переводов идут
через Claude API (`claude-haiku-4-5`, платный). Объём крошечный (центы в месяц), но цель —
ноль платежей вообще, поэтому переезжаем на бесплатный тир Google Gemini API.

## Выбранный вариант: Gemini 2.5 Flash

- Бесплатный API-ключ через Google AI Studio: нужен только Google-аккаунт, карта не нужна.
- Лимиты бесплатного тира (июль 2026): `gemini-2.5-flash` — 250 запросов/день,
  `gemini-2.5-flash-lite` — 1000/день (лимиты раздельные по моделям); сброс в полночь
  по тихоокеанскому времени.
- Один запрос бота = одно добавленное слово ИЛИ одна умная проверка перевода
  (точные совпадения отсекаются `answers_match` без LLM) — реальный день сильно
  меньше лимита.
- Нативный структурированный вывод (`response_schema`) — прямой аналог нашего
  форсированного tool use.

**Отклонённые альтернативы:**
- *OpenRouter free* — без покупки кредитов всего 50 запросов/день, набор free-моделей
  нестабилен, качество непредсказуемо. Рассматривался, отклонён 2026-07-28.
- *Groq free* — лимиты огромные, но открытые модели (Llama и т.п.) хуже держат
  тонкости задачи: пиренейская лексика, правила русской транскрипции, стабильная
  JSON-схема, нейтральные note.
- *Локальная модель на VPS* — дроплет не потянет модель достаточного качества.

**Нюанс прозрачности:** на бесплатном тире Google может использовать содержимое
запросов для улучшения своих продуктов. В запросах — только испанские/русские слова
и учебные ответы, ничего личного. Осознанно принято.

## Что меняется (и что нет)

Меняются только LLM-сервисы, конфиг и точка входа. Хендлеры, БД, тексты бота,
клавиатуры, SRS, TTS — не трогаем; формат данных сервисов сохраняется байт-в-байт:

- `enrichment.enrich(client, text)` → `{kind, spanish, russian, transcription, example_es, example_ru}`
- `grading.grade(client, *, prompt_ru, expected_es, answer)` → `{verdict, correct_spanish, note}`

### config.py

- `ANTHROPIC_API_KEY` → `GEMINI_API_KEY` (обязательный).
- Новые необязательные: `GEMINI_MODEL` (default `gemini-2.5-flash`),
  `GEMINI_FALLBACK_MODEL` (default `gemini-2.5-flash-lite`; пустая строка отключает фолбэк).
- Поле dataclass: `anthropic_api_key` → `gemini_api_key`, плюс `gemini_model`,
  `gemini_fallback_model`.

### bot.py

- `from anthropic import Anthropic` → `from google import genai`.
- Клиент: `genai.Client(api_key=cfg.gemini_api_key)`.
- DI-ключ переименовываем: `dp["anthropic"]` → `dp["llm"]` (нейтральное имя — следующая
  смена провайдера не потребует трогать хендлеры). Параметры хендлеров `anthropic` → `llm`.

### services/enrichment.py и services/grading.py

- Вызов: `client.models.generate_content(model=..., contents=<user text>,
  config=GenerateContentConfig(system_instruction=SYSTEM,
  response_mime_type="application/json", response_schema=<схема>))`.
  Вызов остаётся синхронным — обёртка `asyncio.to_thread` в хендлерах сохраняется.
- Схемы — те же JSON-схемы, что были в `TOOL["input_schema"]` (enum для `kind` и
  `verdict` сохраняются).
- Разбор ответа: `json.loads(response.text)` + валидация `REQUIRED_KEYS` (все ключи
  присутствуют и непустые) — логика `_extract` сохраняется по духу; один ретрай, как сейчас.
- Промпты `SYSTEM` переносятся без изменений (пиренейский испанский, правила
  транскрипции, гендер-нейтральные note). `cache_control` убирается (специфика Anthropic).
- Константа `MODEL` из сервисов уходит — модель приходит из конфига через параметр.

### Лимиты и деградация

Порядок при каждом LLM-вызове:

1. Основная модель (`GEMINI_MODEL`).
2. Ответ 429 / исчерпание квоты → одна попытка на `GEMINI_FALLBACK_MODEL`
   (у неё отдельный дневной лимит).
3. И фолбэк исчерпан → выбрасывается новое исключение `QuotaExceededError`
   (отдельное от `EnrichmentError`/`GradingError`), чтобы хендлеры отличали
   «лимит» от «модель вернула мусор».
4. Ответ 5xx (перегрузка, частый случай — 503) или транспортный сбой →
   **тоже переключение на следующую модель** (правка по факту эксплуатации
   2026-07-30: `gemini-3.5-flash` отдаёт `503 high demand` часами, фолбэк только
   по 429 оставлял бота нерабочим). Все модели легли: чисто 429 →
   `QuotaExceededError`; был хоть один не-429 → сервисный ретрай, затем обычная
   ошибка «попробуй ещё раз» (google-genai, в отличие от anthropic SDK, сам не ретраит).

Поведение хендлеров при `QuotaExceededError`:

- **Добавление слова** (`handlers/add.py`): честное гендер-нейтральное сообщение —
  «Лимит бесплатных ИИ-запросов пока исчерпан 😕 Попробуй позже или завтра.»
  Слово НЕ сохраняется (как сейчас при `EnrichmentError`).
- **Проверка перевода** (`handlers/training.py`): grade вызывается только когда
  точное сравнение уже не совпало → деградация: verdict `wrong`, показываем
  правильный ответ + нейтральная note «умная проверка пока недоступна —
  сравни свой ответ с правильным». SRS обрабатывает как обычное «не вспомнила».
- **Карточки и аудирование** от LLM не зависят — работают всегда.

### requirements.txt

- Убрать: `anthropic==0.39.0`, пин `httpx==0.27.2` (пин был только из-за anthropic).
- Добавить: `google-genai==2.8.0` — НЕ актуальную: версии ≥2.9 требуют pydantic≥2.12,
  а aiogram 3.13.1 — pydantic<2.10 (ResolutionImpossible). 2.8.0 — самая свежая
  совместимая (проверено pip-резолвером 2026-07-28, ревью плана); не поднимать
  без апгрейда aiogram.

### .env / .env.example

`ANTHROPIC_API_KEY` → `GEMINI_API_KEY` (+ опциональные `GEMINI_MODEL`,
`GEMINI_FALLBACK_MODEL` с дефолтами в комментарии).

## Тесты

- Сервисные тесты (`tests/`): моки переводятся с `client.messages.create` на
  `client.models.generate_content` (объект с полем `.text` = JSON-строка).
  Покрыть: успешный разбор, ретрай при мусоре, `QuotaExceededError` после
  фолбэка, работу фолбэк-модели.
- `test_config.py`: новые env-переменные, дефолты моделей.
- Остальные тесты не трогаются; критерий — `pytest -q` зелёный (81+ тестов).

## Деплой (VPS, systemd)

1. Victoria заводит ключ на aistudio.google.com (бесплатно, без карты).
2. На сервере: обновить код (`git pull`), `pip install -r requirements.txt` в venv,
   в `.env` добавить `GEMINI_API_KEY` (старый `ANTHROPIC_API_KEY` пока не удалять —
   упростит откат).
3. `systemctl restart` юнита бота; в журнале — `Start polling`, без
   `TelegramConflictError`.
4. Живая проверка в Telegram: добавить слово (обогащение + превью), проверить
   перевод с намеренной опечаткой (умная проверка).
5. Откат: `git revert` + вернуть `.env` — ключ Anthropic ещё на месте.

## Риски

- **Дневной лимит.** 250+1000 запросов/день на два порядка выше реального
  использования; при исчерпании — мягкая деградация (выше), бот не падает.
- **Качество транскрипции/лексики Flash vs Haiku.** Проверяется на живом тесте
  (шаг 4 деплоя) на 5–10 контрольных словах (llave, cerveza, año, coche, vale…);
  если хуже — крутим промпт, формат данных не меняется.
- **Google меняет лимиты/модели.** Модель и фолбэк — в `.env`, меняются без деплоя.
